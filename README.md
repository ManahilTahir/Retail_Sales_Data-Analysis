# Retail Sales Data Analysis

## Overview
This repository contains an exploratory data analysis (EDA) pipeline executed inside a Kaggle Notebook environment. The analysis evaluates historical retail transactional data to extract revenue insights, identify top-performing product lines, and track core business metrics.

## Key Features
- **Kaggle Environment Workflow:** Optimized for direct execution in Kaggle Notebooks utilizing `kaggle/input` data paths.
- **Data Wrangling:** Automated handling of missing values, timestamp parsing, and categorical data encoding using `pandas`.
- **KPI Analysis:** Calculation of total revenue, average order value (AOV), and profit margins.
- **Visual Analytics:** Time-series trends and regional sales distributions plotted via `seaborn` and `matplotlib`.

## Tech Stack
- **Environment:** Kaggle Notebooks / Jupyter
- **Languages:** Python 3.x
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## How to Run on Kaggle
1. Upload `retail_sales_analysis.ipynb` to **Kaggle Notebooks**.
2. Add your retail dataset to the notebook input (`/kaggle/input/`).
3. Execute all cells sequentially.
